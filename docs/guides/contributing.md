# Contributing to Dudelang

Thank you for considering contributing to the Dudelang project! We welcome all kinds of contributions, whether it's reporting issues, improving documentation, or adding new features.

## Getting Started
### Forking the Repository
1. Fork the [Dudelang GitHub repository](https://github.com/APCP/Dudelang).
2. Clone your fork:
```bash
git clone https://github.com/YOUR_USERNAME/Dudelang.git
```
3. Set up a development branch:
```bash
git checkout -b feature/your-feature-name
```

### Dependencies
Install the required dependencies:
```bash
npm install
```

## Coding Standards
- Follow ES6+ standards
- Use consistent 4-space indentation
- Write clear commit messages

## Testing
Run tests before submitting your pull request:
```bash
npm test
```

## Submitting Changes
1. Push your changes to your fork:
```bash
git push origin feature/your-feature-name
```
2. Create a pull request against the main repository's `main` branch.
3. Add relevant unit tests for new functionality.
