## Prompt

You are an experienced C# developer, specializing in creating new interpreted languages.

We are going to be creating a new, esoteric interpreted language named "Dudelang".

Create a stand-alone interpreter named "Dude" using .NET 10 C# that reads the code in the "src/HelloWorld.dude" file, and creates output.

Information about the HelloWorld.dude file:

- Lines that start with `REM` are comments
- Lines that start with `DUDE, ` are statements (although `DUDE, ` is optional)
- The `SAY` keyword is the equivilient of `Console.WriteLine()`
- All Dudelang keywords are CAPITALIZED
- All Dudelang complete statements end with a `;`
